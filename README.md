# A4P 문서 변환 (obsidian-pdf-ocr)

한글(HWP·HWPX)·PDF·워드·파워포인트·엑셀 파일을 **컴퓨터 안에서 무료로** 옵시디언 마크다운 노트로 바꾸는 플러그인입니다.
인터넷과 API 키가 없어도 됩니다. 스캔본 PDF와 사진은 컴퓨터에 내장된 글자 인식(OCR)으로 읽습니다.

변환 결과는 항상 **원본 파일과 같은 폴더, 같은 이름**으로 만들어집니다 (예: `강의안.hwp` → `강의안.md`).

## 무엇을 바꿀 수 있나요

| 형식 | 변환 방식 | 비고 |
|---|---|---|
| 한글 `.hwp` `.hwpx` `.hml` | 로컬 | 표(칸 합치기 포함)·그림·각주 보존 |
| PDF `.pdf` | 로컬 | 제목·표·글머리표 인식. 스캔된 쪽만 골라 OCR |
| 워드 `.docx` · 파워포인트 `.pptx` | 로컬 | 파워포인트는 **발표자 노트**까지 가져옴 |
| 엑셀 `.xlsx` `.xls` | 로컬 | 시트를 표로 |
| 그림 `.png` `.jpg` `.jpeg` | 로컬 OCR | 사진·스캔 이미지의 글자를 읽음 |
| 옛 형식 `.doc` `.ppt` | Mistral 전용 | 로컬로는 안 됩니다 — 워드·파워포인트에서 `.docx`·`.pptx`로 다시 저장해 주세요 |

변환한 노트에서는 성경 구절을 `[[창1_1]]` 같은 위키링크로 바꾸고(설정에서 끌 수 있음), 원하면 Templater 템플릿도 자동으로 적용합니다.

## 쓰는 법

- **파일 하나**: 파일 탐색기에서 파일을 오른쪽 클릭 → "…를 MD로 변환"
- **여러 파일**: 여러 개를 골라 오른쪽 클릭 → "N개 파일을 MD로 변환"
- **폴더 통째로**: 폴더를 오른쪽 클릭 → "폴더 내 N개 파일을 MD로 변환" (폴더 바로 안의 파일만)
- **감시 폴더**: 설정에서 폴더를 정해 두면, 그 폴더에 새로 들어오는 파일을 자동으로 변환합니다
- **명령어 팔레트**: "MD로 변환" (지금 열린 파일)

## 변환 엔진

설정 → A4P 문서 변환 → **변환 엔진**에서 고릅니다.

- **로컬 (기본, 추천)** — 컴퓨터 안에서 변환합니다. 무료이고 파일이 밖으로 나가지 않습니다.
  변환 엔진으로 한국 문서에 특화된 오픈소스 [kordoc](https://github.com/chrisryugj/kordoc)을 씁니다.
- **Mistral API (유료)** — Mistral OCR 유료 API 키가 있는 분만 씁니다. 스캔본 품질이 가장 좋습니다.
  이때도 한글·엑셀 파일은 Mistral이 지원하지 않아 로컬로 변환합니다.

## 스캔본·사진 글자 인식(OCR)

PDF 안에 글자층이 없는 쪽(스캔한 쪽)이 있거나 그림 파일을 변환하면, 컴퓨터에 내장된 OCR을 씁니다. **따로 설치할 것은 없습니다.**

- **맥**: Apple Vision (macOS 13 Ventura 이상에서 한국어 지원)
- **윈도우**: 윈도우 내장 OCR (**베타**) — 한국어 "광학 문자 인식" 기능이 있어야 합니다.
  한국어 윈도우에는 보통 들어 있고, 없으면 *설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션*에서 "광학 문자 인식"을 설치하세요.
- 설정 화면의 **[OCR 점검]** 단추로 이 컴퓨터에서 한국어 OCR이 되는지 바로 확인할 수 있습니다.
- 휴대폰·태블릿에서는 로컬 변환을 쓸 수 없습니다(PC에서 변환하세요).

## 알아 두면 좋은 점

- **큰 파일**: 수백 쪽짜리 책 PDF는 변환에 수십 초 걸리고, 그동안 옵시디언이 잠깐씩 멈출 수 있습니다.
- **스캔본의 표**: OCR로 읽은 쪽의 표는 칸 구조가 정확히 살아나지 않을 수 있습니다(글은 읽힙니다).
- **암호·보안 문서**: 암호가 걸렸거나 문서 보안(DRM)이 걸린 파일은 변환할 수 없습니다. 원래 프로그램에서 암호를 풀고 다시 저장해 주세요.
- **원본 파일 삭제** 설정을 켜면 변환 뒤 원본은 휴지통으로 갑니다(영구 삭제가 아님).

## 설치 (BRAT)

1. 옵시디언 커뮤니티 플러그인에서 **BRAT**을 설치합니다.
2. BRAT → "Add Beta plugin" → `ai4pastor/obsidian-pdf-ocr` 입력
3. 설정 → 커뮤니티 플러그인에서 **A4P 문서 변환**을 켭니다.

## ⚠️ 알려진 충돌: Paste Image Rename 플러그인

**증상**: 서로 다른 파일을 변환했는데 결과 노트 제목이 전부 똑같고 `-1, -2, -3, -4` 연번만 붙어서 생성됨.

**원인**: 이 플러그인의 문제가 아니라, **Paste Image Rename** 플러그인의 **"Handle all attachments"** 옵션 때문입니다. 이 옵션이 켜져 있으면 볼트에 새로 들어오는 모든 파일(PDF·DOCX·HWP 포함)이 변환되기 전에 "현재 열려 있는 노트 이름 + 연번"으로 즉시 리네임되고, 변환은 그 바뀐 이름을 그대로 따라갑니다.

**해결**: Paste Image Rename 설정에서 둘 중 하나를 적용하세요.

1. **Handle all attachments** 옵션 끄기 (이미지 붙여넣기 리네임은 계속 동작), 또는
2. **Exclude extension pattern**에 다음을 입력해 문서 파일을 리네임 대상에서 제외:

   ```
   pdf|docx|doc|pptx|ppt|hwp|hwpx|xlsx|xls
   ```
